### (d) Stepped dialogue — reusable, UI-free (used by Gideon too)
```gdscript
class SteppedDialogue extends RefCounted:
	var lines: Array[String] = []
	var farewell: String = ""
	var idx: int = -1

	func advance() -> String:            # ONE line per call, clamps at last
		idx = mini(idx + 1, lines.size() - 1)
		return lines[idx]

	func at_end() -> bool:
		return idx >= lines.size() - 1

	func leave() -> String:              # returns farewell + resets
		idx = -1
		return farewell
```
```gdscript
static func make_mira_dialogue() -> SteppedDialogue:
	var d: SteppedDialogue = SteppedDialogue.new()

		"Welcome to the Diamond Vault, darling.",

		"Or crush it: 2888 days, diamond-hard conviction.",
		"Tap CONFIRM when your heart's set.",
	]
	d.farewell = "Come back shiny, sweetheart."
	return d
```
UI glue (thin, no logic): E press → if `idx == -1` show panel; every E calls `advance()`, sets one `style_label(l, 28)` line, shows `[E] next` hint; STAKE/CRUSH/CONFIRM buttons stay hidden until `at_end()`. Never concatenate lines.

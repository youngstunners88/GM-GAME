**T2 – Diamond Vault Clerk Big-Button Spec**

1. **Node tree** (inside `vault_realm.tscn`):  
   `PanelContainer (ClerkPanel)` → `HBoxContainer` →  
   - `TextureRect (MiraPortrait)` – founder Mira Voss art, `custom_minimum_size = Vector2(140,140)`, `expand_mode = FIT_WIDTH_PROPORTIONAL`.  
   - `VBoxContainer (Controls, separation 12)` →  
     - `Label (Holdings)` – font_size 28, outline_size 7, outline_color BLACK.  
     - `HBoxContainer (StakeRow)` – Label “STAKE 7D”, Button “-”, Label `_stake_amt`, Button “+”, Button “LOCK”.  
     - `HBoxContainer (CrushRow)` – Label “CRUSH BLAZE”, Button “-”, Label `_crush_amt`, Button “+”, Button “CRUSH”.

2. **Data & clamping** (script `vault_realm.gd`):  
   - `_stake_amt`: `clamp(value, 0, GoldMineSystem.diamonds_balance)`.  
   - `_crush_amt`: `clamp(value, 0, min(GoldMineSystem.blaze_diamonds, GoldMineSystem.BLAZE_DIAMOND_STACK_LIMIT))`.

3. **Button actions** (all disabled when amount == 0):  
   - “LOCK” → `GoldMineSystem.stake_diamonds(_stake_amt, 7); _stake_amt = 0; refresh()`.  
   - “CRUSH” → `GoldMineSystem.crush_blaze_diamonds(_crush_amt); _crush_amt = 0; refresh()`.

4. **Visual polish** (all Labels):  
   `add_theme_font_size_override("font_size", 28..32)`, `add_theme_constant_override("outline_size", 7..8)`, `add_theme_color_override("font_outline_color", Color.BLACK)`. Buttons `custom_minimum_size = Vector2(80,48)`.

5. **Portrait**: sits left of the VBox, vertically centered via `VBoxContainer.alignment = ALIGNMENT_CENTER`.

1. **States**: IDLE (no player), NEAR (prompt visible), DIALOGUE (stepping lines), FAREWELL (exit line).  
2. **Floor anchor**: Mira Sprite2D.position = Vector2(0, -sprite_height/2) under clerk Node2D; clerk placed at floor Y so feet sit on tile, not floating.  
3. **Facing**: In `_process`: `var to_player: int = sign(player.global_position.x - global_position.x)`; if `to_player != 0`: `sprite.scale.x = to_player`.  
4. **Trigger**: Area2D “TalkZone” `body_entered` → state NEAR (show “[E] Talk”); `body_exited` → if state == DIALOGUE: trigger FAREWELL.  
5. **Stepped lines**: `var lines: Array[String]`; `var idx: int = 0`. On `ui_accept`: if `idx < lines.size()`: `dialog_label.text = lines[idx]`; `voice.play()`; `idx += 1`; hint_label shows “E – Next” or “E – Close” when `idx == lines.size()`. Else: `close_ui()`.  
6. **Farewell**: On zone exit show farewell line, play voice, `await get_tree().create_timer(1.5).timeout`, hide panel, return IDLE.

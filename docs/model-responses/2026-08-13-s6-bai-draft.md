1. **State** — UI panel reads `GoldmineSystem.diamonds_balance` and new `GoldmineSystem.blaze_diamonds` (populated by `BlazeRush` when dash-collecting). Display two counters: “$DIAMONDS: X” and “BLAZE DIAMONDS: Y / 10”. Gray-out a section if its count is 0.

2. **Stake $DIAMONDS** — Slider `stake_amt: int` range `[0, GoldmineSystem.diamonds_balance]`. Clamp on every change: `stake_amt = clamp(stake_amt, 0, GoldmineSystem.diamonds_balance)`. Add days selector (288–2888). If balance is 0, skip to step 3.

3. **Crush Blaze Diamonds** — Slider `crush_amt: int` range `[0, min(GoldmineSystem.blaze_diamonds, STACK_LIMIT)]` where `const STACK_LIMIT: int = 10`. Clamp on change. Show preview: “Gain %d $DIAMONDS” % (crush_amt * 2).

4. **Confirm → Apply** — Single “Execute” button. On press:
   ```gdscript
   if stake_amt > 0: GoldmineSystem.stake_diamonds(stake_amt, selected_days)
   if crush_amt > 0:
       GoldmineSystem.blaze_diamonds -= crush_amt
       GoldmineSystem.diamonds_balance += crush_amt * 2   # Crush rule
   ```
   Close UI and play crush SFX. Disable button until operation finishes.

5. **Edge Cases** — **Zero owned**: Hide the relevant slider group and show “None held”. **Over-clamp**: Slider hard-limits prevent overflow; ignore out-of-range typed input. **Double-confirm**: Set `execute_btn.disabled = true` immediately on press; re-enable only if validation fails.

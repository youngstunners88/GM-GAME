## 1. Diamond Vault clerk hierarchy

**Biggest → smallest**
1. **Action buttons** (primary): STAKE / CRUSH / HOLDINGS / CONFIRM — large hit targets, full-width or 2×2 grid
2. **Amount readout** (secondary): current stake/crush value
3. **Mira prompt** (tertiary): one short line
4. **Hints / plate labels** (smallest)

**On busy blue/gold**
- Fill: near-white or warm gold (`Color(1, 0.95, 0.75)`)
- Outline: black, `outline_size ≈ font_size/4` (e.g. 28→7, 22→5)
- Buttons: dark plate + gold border so they pop off blue; selected = brighter gold fill

**Layout order (top → bottom)**
1. Holdings strip (always visible, large)
2. `[STAKE $DIAMONDS]` `[CRUSH BLAZE]`
3. Amount − / value / + 
4. `[CONFIRM]` (dominant)
5. Mira line under the plate

# Script Lab — Smoke Content Engine

## What happens here
Thinking only. Ideas in, locked script and shot list out. No renders. Work is
per-drop: the locked outputs live in `../calendar/drops/NNN_slug/`
(`brief.md`, `script_final.md`, `script_shots.md`). Use `ideas/`, `drafts/`,
`final/` here as the scratch/staging area before a drop is scaffolded.

## Voice
- Street, funny, high-energy, slightly dangerous lounge energy.
- Lil Blunt is the mascot / lead of the Smoke Realm — not a random stoner extra.
- Protocol words stay accurate: $SMOKE, Solana, weekly bong parties,
  wrapped-Smoke NFTs, SOL rewards for NFT buyers at the bong party.
- Short sentences. Hooks in the first 1.5 seconds.

## Audience
Solana crypto twitter, cannabis-culture degens, existing Smoke Ring /
LilBlunt.win people, NFT flippers who want party utility.

## Process (per drop)
1. Idea seed comes from `../calendar/calendar.md` backlog (or dump new hooks in `ideas/`).
2. Astra GPT-6 expands 3 hook options (skill: `astra-lead`).
3. Founder locks one hook.
4. Write draft → final into the drop folder's `script_final.md`.
5. Write `script_shots.md` beat-by-beat, following the drop's **format** skeleton
   (see `../formats/`); mark the 10s hero window.
6. Hand off to `/production`.

## Good work
- One promise per drop
- Hero 10s is the single most rewatchable beat
- No unexplained token mechanics, no competitor names
- Visual notes faithful to founder reference images — do not invent a new mascot

## Files
- `ideas/` — hook dumps (`idea-hook-name.md`)
- `drafts/` — staging
- `final/` — staging before it lands in the drop folder
- Locked per-drop outputs live under `../calendar/drops/NNN_slug/`

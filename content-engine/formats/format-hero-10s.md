# Format: hero-10s

## One-liner
The single most rewatchable 10 seconds — quote-tweet bait that loops or stands
alone. The one place Seedance 2.5 is allowed.

## Output spec
- Length: 10s
- Model / tool: **Seedance 2.5 — one clip only** (or a clean cut of the
  hype-30s hero window if 2.5 budget is spent)
- Aspect ratio: 9:16
- Deliverables: `YYYY-MM-DD_<slug>_hero10s.*` posted as its own asset

## Beat structure
1. **Cold open on the peak** — no wind-up. The drop, party, reward flash, or
   character hit at second zero.
2. **Hold the money frame** — the shot people screenshot.
3. **Loop-friendly out** — last frame can flow back to the first.

## Must-include (brand-locked)
- Lil Blunt, on-model, same design language as the parent drop
- The one peak moment only — no new story

## Must-not
- Use Seedance 2.5 for anything longer than this 10s
- Add new claims the parent drop didn't already lock
- Burn in fake numbers

## Hero window
This *is* the hero window. If cut from a hype-30s, use the exact marked band;
if a dedicated 2.5 render, cover only that 10s.

## Distribution default
Posted as its own asset (not just trimmed in-app). One line + link. Great as a
T+hours quote-bait follow to the 30s anchor.

## Definition of done
- [ ] 10s, loops or stands alone
- [ ] On-model with parent drop
- [ ] Seedance 2.5 used at most once per drop
- [ ] Posted as a standalone asset with its own caption
- [ ] Render id + cost logged in STATUS.md

# Format: hype-30s

## One-liner
The weekly anchor — a 30-second story clip that hooks in 1.5s and lands on a
clear $SMOKE / bong-party CTA.

## Output spec
- Length: 30s
- Model / tool: Seedance 2 (all story shots)
- Aspect ratio: 9:16 first (X/TikTok); 16:9 only if founder asks
- Deliverables: `YYYY-MM-DD_<slug>_30s.*` master + a marked 10s hero window
  that can spin off a `hero-10s` drop

## Beat structure (timestamps)
1. **0.0–1.5s — Hook.** One promise, high energy. Lil Blunt on screen fast.
2. **1.5–8s — Setup.** What's happening / the world of the Smoke Realm.
3. **8–20s — Party peak.** The rewatchable middle. Mark the **10s hero window**
   inside this band.
4. **20–27s — Payoff.** Wrapped-Smoke NFT / SOL-reward eligibility beat (locked
   claim only).
5. **27–30s — CTA.** $SMOKE on Solana + LilBlunt.win + follow @smokering25.

## Must-include (brand-locked)
- Lil Blunt as the locked mascot, consistent design/wardrobe/lighting across shots
- $SMOKE + Solana in the payoff/CTA
- Bong party as the recurring anchor ("this Friday")

## Must-not
- Fake ticker prices, TVL, APY, or "guaranteed SOL"
- Swap Seedance 2.5 onto the full 30s
- Add characters/brands not in the locked brief

## Hero window
The 8–20s party-peak band. Mark the exact 10s in `script_shots.md` so a
`hero-10s` drop can cut or re-render it.

## Distribution default
X primary (@smokering25), site embed on LilBlunt.win, TikTok if greenlit.
Caption skeleton = `distribution-smoke` 30s skeleton. Max 2 hashtags.

## Definition of done
- [ ] 30s narrative complete: hook / party peak / launch CTA
- [ ] Same character design + lighting across all shots
- [ ] 10s hero window marked
- [ ] No fake numbers, no invented claims
- [ ] Master in `output/`, failed takes stay in `builds/`
- [ ] Render ids + costs logged in STATUS.md

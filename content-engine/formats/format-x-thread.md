# Format: x-thread

## One-liner
A text thread for X that explains one thing (how the bong party works, how
wrapped-Smoke NFTs get you in) or carries launch-day narrative — no render.

## Output spec
- Length: 3–7 posts
- Model / tool: none (Astra drafts copy, Claude files it)
- Deliverables: thread in `posts/` as `YYYY-MM-DD-x-<topic>.md`

## Beat structure
1. **Post 1 — Hook.** The promise / the question. Stands alone if it's all
   someone reads.
2. **Posts 2–N — One idea each.** Build the explanation, one locked fact per post.
3. **Last post — CTA.** $SMOKE on Solana + LilBlunt.win + follow @smokering25.

## Must-include (brand-locked)
- Only Gitbook/founder-locked facts: weekly bong party, wrapped-Smoke NFTs,
  SOL-reward eligibility for NFT buyers at the party
- $SMOKE + Solana named correctly

## Must-not
- Invent tokenomics, APY, MC, or "guaranteed SOL"
- Competitor names or random KOL tags unless the founder lists them
- 8-hashtag spam

## Distribution default
X primary. If a video drop exists on the same topic, attach the master to post 1.

## Definition of done
- [ ] Every factual claim traces to Gitbook/founder brief
- [ ] Hook stands alone
- [ ] CTA present
- [ ] Logged in STATUS.md + calendar board

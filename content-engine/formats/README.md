# Formats

A **format** is a reusable recipe for a kind of drop. It fixes the structure so
each new drop is a fill-in, not a blank page — that is the repeatable core of
the engine.

Pick a format when grooming the calendar; `drop-runner` copies the format's
shape into the new drop folder.

| Format | File | Length | Model | Use for |
|--------|------|--------|-------|---------|
| Hype 30s | `format-hype-30s.md` | 30s | Seedance 2 | Weekly anchor story clip |
| Hero 10s | `format-hero-10s.md` | 10s | Seedance 2.5 (one clip) | Rewatchable peak / quote-bait |
| Still post | `format-still-post.md` | 1 image | MuAPI still | Reactive meme / reply-bait |
| X thread | `format-x-thread.md` | text | — | Explainer / launch-day thread |

Add a new format by copying `format-template.md`. Keep every format faithful to
`../CLAUDE.md` hard rules (no protocol invention, prompt fidelity, no fake
numbers).

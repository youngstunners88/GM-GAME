# Format: still-post

## One-liner
A single brand-locked image for reactive / reply-bait posting between video
drops — keeps the feed warm without a render budget.

## Output spec
- Length: 1 image
- Model / tool: MuAPI still (see `game-aesthetics-forge` repo skill for the
  Muapi Flux path and manifest-driven prompts)
- Aspect ratio: 1:1 or 9:16 depending on placement
- Deliverables: one image in `output/` + caption in `posts/`

## Beat structure
1. One visual idea (Lil Blunt reaction, party still, reward moment).
2. One line of copy that carries the joke or the promise.

## Must-include (brand-locked)
- Lil Blunt on-model
- Any claim stays inside the locked set

## Must-not
- Fake numbers or invented mechanics in the image or caption
- Off-model mascot / borrowed IP

## Distribution default
X reply/quote or standalone. One line, ≤2 hashtags, link only if it adds value.

## Definition of done
- [ ] On-model image in `output/`
- [ ] Caption written, no fake claims
- [ ] Logged in STATUS.md + calendar board

# Tone (founder: "some congratulations spoken with a cool little jingle. Nothing too long or too serious")
Chill, playful, 3 seconds of audio in total: jingle (~2.2 s) then Lil Blunt's line (<= 4 s, < 60 characters). Card shows 5.5 s then fades.
No speeches, no jargon, no protocol lecture. Boss NFTs get the triumphant jingle, test NFTs the bright "smart" one.

# Pieces
- Card: `NftIssuer._show_card` (CanvasLayer 95, process ALWAYS so it also shows inside the paused protocol rooms). Gold border, dark panel,
  non-green translucency (blotch rule). Last line is the honest ICP status (see `gm-game-nft-icp-issuance`).
- Audio: `src/assets/nft/audio/jingle_boss.mp3`, `jingle_test.mp3`, `<nft_id>_voice.mp3`. Generated by `python3 scripts/gen_nft_audio.py`
  (ElevenLabs, `ELEVENLABS_API` = founder account, Lil Blunt voice HMGfKwZCRujgXyRDUW0b, loudnorm -14 LUFS). Lines live in `src/data/nft_collection.json` (`spoken`).
  Spell "NFT" as "N F T" in the spoken text so the voice does not mangle it.
- Mix: voice +8 dB (the music drowned governors before), jingle +2 dB, NO music ducking (founder hated the music dipping).
- Voice plays after the jingle (1.7 s), never on top of it.

# Change a line / regenerate
Edit `spoken` in the json, then `python3 scripts/gen_nft_audio.py --force` (regenerates everything; delete a single mp3 and run without --force to redo one).
Run `tests/nft_issuer_test.tscn`; ship; verify live. Look at the card in a real render (`see-it-yourself`) before saying it looks right.
